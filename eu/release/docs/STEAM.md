# Add TombiRecomp EU to Steam

Automatic shortcut registration was not implemented: no reliable supported
one-click import was established within the finalization budget. The program
will not edit Steam shortcuts.vdf, account files, settings or registry entries.

Use Steam's supported manual workflow:

1. Open Steam's Games menu and choose the option to add a non-Steam game.
2. Browse to TombiRecompEU.exe in the extracted windows-x64 folder.
3. Select it and confirm adding the selected program.

Keep the complete runtime folders beside the EXE. After moving the installation,
update the Steam shortcut. Launch once normally to select your own EU disc.
If Steam Input supplies a virtual controller, select that device in the game
launcher and avoid two simultaneous mappings for the same physical pad.

Valve's instructions:
https://help.steampowered.com/en/faqs/view/4B8B-9697-2338-40EC

This creates a local shortcut, not an official Steam release or Steam update
channel. No Steam integration was executed on the owner's account during tests.
