Tombi! (Europe, SCES-01331) - v0.22.0-alpha - Windows x64

Extract into a writable folder and run TombiRecompEU2.exe.
Choose your own original SCES-01331 CUE in Browse For Disc. Keep its BIN beside it.
The complete data track is verified. Press PLAY and use the original language menu.
English, Spanish, Portuguese, Swedish and Danish are supported.
No PowerShell or installed development tools are required.

Seamless Loading is enabled under Mods. Controller, video, audio and fullscreen
use the shared launcher. Geometry Optimization, PGXP and Hybrid Controller are
optional. Geometry defaults ON as in EU1; PGXP and Hybrid default OFF. HD Texture Packs requires a compatible external
SCES-01331 pack; Bezel Artwork requires your own image. Fast Forward and HQ SPU
use the shared runtime/audio options. Widescreen is optional in Mods: choose
Fit to Window, 16:9, 21:9 or 32:9. FMV Skip remains unavailable.
Cards persist under saves/SCES-01331 in this writable package folder.
Card Browse uses exactly the official US/EU1 file picker.
New creates a card and refuses to overwrite existing files; choose a new filename.
Back up a card before importing it. Never interrupt an active game save.

Includes freely licensed OpenBIOS and runtime fallback dependencies with notices.
No Sony BIOS, game image or personal memory cards are included.
This is not full campaign certification. Portuguese game-over retains the audited
interpreter fallback. The first native DLL compatibility sweep may take time.
